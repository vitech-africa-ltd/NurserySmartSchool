## 🎨 Design System

### Composants Réutilisables

**Cartes**
```tsx
<div className="bg-white p-6 rounded-2xl border border-gray-100 hover:shadow-md transition-shadow">
  {/* Contenu */}
</div>
```

**Boutons**
```tsx
<button className="gradient-primary text-white px-4 py-2.5 rounded-xl font-medium text-sm flex items-center gap-2">
  <Plus size={16} /> Action
</button>
```

**Formulaires**
```tsx
<input className="w-full border border-gray-200 rounded-lg px-3 py-2 text-sm focus:ring-2 focus:ring-blue-500" />
```

**Modals**
```tsx
<div className="fixed inset-0 bg-black/50 z-50 flex items-center justify-center p-4">
  <div className="bg-white rounded-2xl p-6 w-full max-w-md">
    {/* Contenu modal */}
  </div>
</div>
```

## 🚀 Comment Utiliser

### 1. Lancer l'application
```bash
npm run dev
```

### 2. Se connecter
- Admin : admin@nursery360.rw
- Teacher : teacher@nursery360.rw
- Parent : parent@nursery360.rw
- Mot de passe : n'importe lequel (mode démo)

### 3. Naviguer
- Utiliser la sidebar gauche
- Cliquer sur les emojis pour identifier les sections
- Explorer toutes les pages

### 4. Tester les fonctionnalités
- Ajouter des enfants, enseignants, classes
- Marquer la présence
- Créer des annonces
- Générer des rapports
- Uploader des documents
